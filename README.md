Learning to code by shipping small, real things instead of just doing tutorials.

## Why this exists

I'm building this hub for three reasons:
1. **Resume proof** — real, working links beat "I know a bit of coding."
2. **Freelance portfolio** — each project is something I can show a client and say "I can build you something like this."
3. **A path to income** — the flagship project (#3) is the one I'm trying to actually sell or use to land freelance work.
