# Expense Splitter

A no-backend, no-signup tool that splits shared expenses fairly between a group and tells you exactly who should pay whom.

**Live demo:** _(add your GitHub Pages / Netlify link here once deployed)_

## What it does
- Add any number of people to a group
- Log expenses and who paid for each one
- Automatically works out each person's fair share
- Shows the minimum number of payments needed to settle up (not just "everyone owes everyone")

## Why I built it
This was project #1 in a self-directed plan to learn web development by shipping small, real tools instead of tutorials. Goals: practice vanilla JS (DOM manipulation, state, events), and end up with something people can actually use — like splitting a dinner bill or a trip's shared costs.

## Tech
Plain HTML/CSS/JavaScript — no frameworks, no build step, no dependencies. Open `index.html` in any browser.

## What I'd add next
- Save state to localStorage so a session isn't lost on refresh
- Support uneven splits (e.g. someone only owes for their own item)
- Shareable link / QR code so a group can fill it out together
